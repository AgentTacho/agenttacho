**Scope**: The rework only. The first version (operators, case-insensitive literal and regex matching, `MatchRuntime` with the 50 ms limit, sit-out, retry memory and given-up state, re-attribution in `LogIndex`, `CodexSessionSource` and `OpenCodeSource`, `validateForSaving()`, `ConditionControls`, `StableWidthPicker`, `MatchRuleNotes`) is on the branch and is reused; tasks only move or adapt it.

Invented examples only (`intranet/`, `glm`, `gateway-a/`, `proj-alpha`, `~/.claude-gateway`); never real model names, account names or paths. Rename files with `git mv` so their history stays.

## Implementation Strategy

MVP is Phase 2 plus US1: the model swap and the fix that a condition never takes another kind's or a subscription's records. Then US2 (gateway without a condition, P1), US3 (operators as conditions, refusal), US4 (the Settings section that exposes it all) and US5 (log notes and the demo scenario). Each phase ends with `make test` passing; US4 ends with `make app` and `make app-demo`.
